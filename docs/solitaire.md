# Solitaire (Klondike / Косинка)

Open **Apps > Games > Solitaire (Klondike)**. This is draw-one Klondike with
a standard 52-card deck, seven tableau columns, a stock/waste pair, and four
foundations. It runs offline.

Build tableau columns downward in alternating colours. Move any face-up
descending stack onto the next higher card of the other colour. An empty
column accepts a King or a stack starting with a King. Build foundations
upward from Ace to King in the same suit. The exposed tableau card turns
face up automatically after a move.

Tap a face-up card to select it, then tap its destination column or foundation.
Tapping the selected card again cancels selection. Only the top waste or
foundation card can be moved. On monochrome screens, hearts/diamonds are the
red suits and clubs/spades are the black suits. The card labels use **H/D**
for the outlined red suits and **C/S** for the filled black suits.

- **Stock** draws one card. When the stock is empty, tap it again to recycle
  the waste; recycling is unlimited.
- **Undo** reverses the latest accepted action. Up to eight actions are retained,
  including draws, recycling, transfers, and automatic flips.
- **Auto** moves one available tableau or waste card to a legal foundation.
  Undo is available if you want to reverse that choice.

Long columns have **U/D** scrolling controls so every face-up card remains reachable
in portrait and landscape. Card selection and scrolling do not count as moves.

Physical controls: Left/Right move the cursor between piles; Up/Down move
between the top row and tableau cards. Center selects a card or attempts the
move, and draws when the stock is focused. Back opens the pause menu.
The touch footer's **Menu** opens the pause menu; **Games** returns to the
chooser. The pause menu offers **Resume**, **New game**, **Undo**, and
**Choose game**.

Move all 52 cards to the foundations to win. A **You won!** dialog then offers
**Close** to return to Games and **Play Again** to deal a new game. Touch either
button, or select with the direction buttons and confirm with Center.
Deals are shuffled, so some may
be unwinnable. A new deal resets the undo history. Game state stays in memory
for the current game; starting it again from the chooser deals a new deck.
